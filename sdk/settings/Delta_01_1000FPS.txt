//////////////////////////////////////////////////////////////////
//////////////        External Trigger Mode Examples      ///////
//////////////////////////////////////////////////////////////////

// [Selecting a trigger mode]
// Examples below. To use a mode, remove conflicting register entries above
// and use the values in the selected block instead.
//
// [Metadata]
// 32B8=00: Timestamp - records elapsed sensor time.
// 32B8=01: Frame index - records frame output order using REF/SUB counters
// instead of elapsed time, so frames can be identified like frame numbers.
//
// [Counter reset - only when needed]
// To restart timestamp/index counters, configure the trigger mode first,
// then perform these steps with acquisition stopped, before START:
// 1) 3A00=00              : disable external trigger input.
// 2) 32B6=00, 32B7=01     : release reset and select register-controlled reset.
// 3) 32B6=01              : assert reset; wait at least 2 ms.
// 4) 32B6=00, 32B7=00     : release reset and restore the normal reset source.
// 5) 3A00=01              : re-enable external trigger input.

// [Single Mode] One frame per rising edge; input <= 1000 Hz.
//20:0100=00 // Acquisition stopped
//20:303B=40 // Disable trigger routing while configuring
//20:3A00=00 // External trigger disabled
//20:3283=01 // DTAG external trigger
//20:3A02=00 // Single
//20:320C=1F // Triggered scan, Global Reset enabled
//20:3A01=01 // Rising edge
//20:3A10=01 // One frame per trigger
//20:3225=00 // GR_ON high byte
//20:3226=01 // GR_ON = 1 frame
//20:3227=00 // GR_OFF high byte
//20:3228=00 // GR_OFF = 0 frames
//20:32B6=00 // Reset released
//20:32B7=00 // Restore normal reset source after one-shot reset
//20:32B8=00 // Timestamp; use 01 for Frame index
//20:32B9=00 // Register timestamp update disabled
//20:3A00=01 // External trigger enabled
//20:303B=42 // External input routing

// [Burst Mode] One rising edge starts continuous capture.
// FRAME_WIDTH does not limit the number of frames in this mode.
//20:0100=00 // Acquisition stopped
//20:303B=40 // Disable trigger routing while configuring
//20:3A00=00 // External trigger disabled
//20:3283=01 // DTAG external trigger
//20:3A02=01 // Burst
//20:320C=3D // Continuous scan, Global Reset disabled
//20:3A01=01 // Rising edge
//20:3A10=01 // Default FRAME_WIDTH
//20:3225=00 // GR_ON high byte
//20:3226=01 // Default GR_ON = 1
//20:3227=00 // GR_OFF high byte
//20:3228=00 // Default GR_OFF = 0
//20:32B6=00 // Reset released
//20:32B7=00 // Restore normal reset source after one-shot reset
//20:32B8=00 // Timestamp; use 01 for Frame index
//20:32B9=00 // Register timestamp update disabled
//20:3A00=01 // External trigger enabled
//20:303B=42 // External input routing

// [BurstSingle Mode] N frames per rising edge; approximately 1 ms between frames.
// Input Hz x N <= 1000. Example: 500 Hz x 2 = 1000 frames/s.
// Set 3A10=N and GR_ON=1, GR_OFF=N-1. Register values below are hexadecimal.
// N=1: 3A10=01 / 3228=00; N=2: 02 / 01; N=3: 03 / 02; N=4: 04 / 03.
//20:0100=00 // Acquisition stopped
//20:303B=40 // Disable trigger routing while configuring
//20:3A00=00 // External trigger disabled
//20:3283=01 // DTAG external trigger
//20:3A02=11 // Burst single
//20:320C=1F // Triggered scan, Global Reset enabled
//20:3A01=01 // Rising edge
//20:3A10=02 // FRAME_WIDTH = N (example: 2)
//20:3225=00 // GR_ON high byte
//20:3226=01 // GR_ON = 1 frame
//20:3227=00 // GR_OFF high byte
//20:3228=01 // GR_OFF = N-1 (example: 1)
//20:32B6=00 // Reset released
//20:32B7=00 // Restore normal reset source after one-shot reset
//20:32B8=00 // Timestamp; use 01 for Frame index
//20:32B9=00 // Register timestamp update disabled
