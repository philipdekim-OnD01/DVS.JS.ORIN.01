# 디코더 설정창

실시간 뷰어의 오른쪽 위 **설정** 버튼을 누릅니다. Jetson .121에서는
<http://192.168.0.121:8080/>를 사용합니다. 설정창을 열어도 수신은 계속됩니다.

## 센서 레지스터

**MIPI / RAW2**, **감도**, **이벤트·그룹**, **센서 ROI** 주소 모음을 선택하고
**레지스터 읽기**를 누릅니다. 직접 주소를 입력할 때는 `0x3901, 0x3907, 0x3908`
처럼 16진수 주소를 쉼표 또는 공백으로 구분합니다. 한 번에 최대 16개,
1초 간격으로 읽을 수 있습니다. 자동 폴링은 하지 않습니다.

표의 **센서 실제값**은 `/dev/i2c-2`, 7-bit 주소 `0x10`의 센서에서 읽은 8-bit 값입니다.
**설정 기대값**은 현재 수신 시작 시 지정한 setfile의 마지막 설정값입니다.
설정 파일이나 V4L2의 캐시된 레지스터 목록을 실제 센서 값처럼 표시하지 않습니다.
드라이버가 직접 관리하는 `0x0100`은 기대값 비교에서 제외합니다.
상태·자체 초기화 레지스터는 설정 기대값과 달라도 고장을 의미하지 않을 수 있습니다.

현재 제공하는 센서 메뉴는 읽기 전용입니다. 감도·그룹·ROI 메뉴도 해당 레지스터의
조회 메뉴이며 센서 값을 쓰지 않습니다. PLL, 링크 속도, 초기화, 스트림 제어는 변경하지 않습니다.

## 영상·표시

프리뷰 합성 간격, 이벤트 극성(ON/OFF), 노이즈 제거, 좌우·상하 반전,
표시 ROI, 화면 일시정지, PNG 저장을 사용할 수 있습니다.
표시 ROI는 지정한 센서 좌표 범위 밖을 배경색으로 숨기는 기능입니다.
센서 ROI 레지스터를 수정하지 않으며 녹화 원본에도 영향을 주지 않습니다.

프리뷰 합성 간격은 수신기의 공통 설정이므로 연결된 모든 뷰어에 적용됩니다.
그 밖의 표시 설정은 해당 브라우저에서만 적용됩니다. RAW2 후보 시각 기반의
Time Surface·감도 쓰기·프로파일 적용은 이 버전의 기능으로 제공하지 않습니다.

## 수신 상태와 설정 파일

**수신 상태**에서 커널, 디코딩 형식, 수신 누락, 버퍼 고갈, 오류 버퍼와
RAW2 시각 관련 카운터를 조회합니다. **상태 새로고침**으로 다시 읽습니다.
RAW2 시각 모호성·역행은 CSI 수신 오류와 별개이며, 누적값을 함께 확인해야 합니다.

**설정 파일**에는 파일명·경로·SHA-256·설정 순서·주석이 표시됩니다.
주소·값·설명으로 검색할 수 있습니다. 중복 주소도 원래 순서대로 보존합니다.
실행 중 파일을 편집해도 적용된 것으로 표시하지 않도록 시작 시 스냅샷을 유지합니다.

## 업데이트와 검증

이미 빌드된 Jetson에서 Python/web만 갱신할 때 다음을 사용합니다.
먼저 `./dvs status`에서 녹화 중이 아닌지 확인합니다.

```bash
python3 -m unittest discover -s tests -p test_sensor_settings.py -v
./dvs stop
cmake --build app/dvs_streamer/output/GCC-arm64 --config Release --target dvs_streamer_runtime
./dvs start
python3 tests/check-settings-api.py --read
```

브라우저를 새로고침합니다. 이 업데이트에는 커널 모듈 재설치나 재부팅이 필요하지 않습니다.
최초 설치 및 전체 앱 빌드는 [디코더·뷰어 설치 가이드](DECODER-AND-VIEWER.md)를 따릅니다.
기존 실행본에 `sensor_settings.py`를 함께 배포해야 합니다.

I2C 장치는 `philip` 계정의 기존 `i2c` 그룹 권한을 사용합니다. sudo 서버나
비밀번호 저장은 필요하지 않습니다. 드라이버 바인딩과 최근 정상 수신 상태를 확인하고,
16-bit 주소 지정 후 1-byte 읽기를 하나의 `I2C_RDWR` 트랜잭션으로 실행합니다.
신규 API는 요청 크기·주소 개수·주기를 제한하며 동일 출처와 프로세스별 토큰을 확인합니다.
기존 LAN 뷰어 전체에 사용자 인증을 추가한 것은 아니므로 외부 공개용 서버로 사용하지 않습니다.
