### 테스트와 실행 명령

아래는 수행 명령의 portable 표기다. `INPUTS`는 위의 읽기 전용 복사본 폴더,
`WEIGHTS`는 저장소 밖 모델 캐시다. 전용 venv Python을 사용했고 working directory는 모듈 루트다.

```sh
python -m pytest -q
python -m pip check
python -m person_yolo --snapshot "$INPUTS/snapshot-00.bin" "$INPUTS/snapshot-01.bin" \
  "$INPUTS/snapshot-02.bin" "$INPUTS/snapshot-03.bin" "$INPUTS/snapshot-04.bin" \
  --dry-run --output benchmarks/evidence-20261102/snapshot-dry-run.jsonl
python benchmarks/run_benchmark.py --metrics benchmarks/evidence-20261102/snapshot-metrics.json -- \
  --snapshot "$INPUTS/snapshot-00.bin" "$INPUTS/snapshot-01.bin" "$INPUTS/snapshot-02.bin" \
  "$INPUTS/snapshot-03.bin" "$INPUTS/snapshot-04.bin" --config configs/p0.json --weights "$WEIGHTS" \
  --output benchmarks/evidence-20261102/snapshot-yolo.jsonl
python benchmarks/run_benchmark.py --metrics benchmarks/evidence-20261102/synthetic-metrics.json -- \
  --synthetic moving --frames 3 --config configs/p0.json --weights "$WEIGHTS" \
  --output benchmarks/evidence-20261102/synthetic-yolo.jsonl
```
