# 공유 RP5 DVS 영상 후처리 검증 — 2026-11-07

## FACT

- 사용자가 제공한 RP5 저장소의 실제 DVS 시각화 영상을 다운로드하여 기존 독립 후처리 앱과 같은 backend CLI로 처리했다.
- 입력은 **960×720, 60fps, 10초, 600프레임**, 46,218,593 bytes의 MP4이다.
- YOLO11n CPU, confidence 0.25, IoU 0.7, imgsz 640, threads 2에서 **600/600 프레임 추론 완료, person 검출 0건**이다.
- 결과는 600프레임의 `annotated.mp4`, 600행의 `detections.jsonl`, `summary.json`이다. 결과 MP4를 다시 디코딩하여 프레임 수와 해상도를 검증했다.
- 이 결과는 **디코딩된 시각화 영상 입력**이다. 모든 결과에 `source_kind=decoded_video`, `raw2_direct=false`를 기록했다.
- 기존 receiver, driver, SDK, sensor 설정은 변경하지 않았다. 브랜치와 PR #3에서만 기록하며 main에 병합하지 않는다.

## RISK

- **0검출은 무인 판정이 아니다.** 라벨이 없어 정확도·재현율을 계산할 수 없다.
  RGB/COCO 학습 모델과 DVS 표시 영상의 도메인 차이가 있으며, 현 입력·설정에서 사람 검출 가능성은 입증되지 않았다.
- MP4의 600개 표시 프레임과 RAW2 Release의 16,140개 버퍼 간 동일 세션·프레임 대응 관계는 검증하지 않았다.
- 영상의 nominal FPS를 사용하며 sensor timestamp, CSI ECC/CRC, V4L2 sequence를 영상에서 복원하지 않는다. 원본 RAW2 무손실 처리 결과가 아니다.
- RAW2 메타데이터의 sequence gap 0 및 error flag 0은 sensor/CSI 손실 없음이나 지속 SD 기록 성능을 증명하지 않는다.
- 출력은 CFR이며 원본 오디오를 보존하지 않는다. Jetson GPU 및 장시간 성능은 별도 검증 대상이다.
